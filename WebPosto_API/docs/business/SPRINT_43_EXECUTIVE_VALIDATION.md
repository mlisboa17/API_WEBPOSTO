# Sprint 43 — Validação Executiva e Melhoria Orientada por Uso

## Objetivo

Validar a Presidência 2.0 com Presidente/Diretor em leitura de 30 segundos, medir adoção
sem expor conteúdo executivo, revisar os quatro blocos com evidência de uso, publicar o
relatório mensal **Business Value Generated by AI** e homologar canal externo de
notificação — sempre com dados reais e sem oportunidades inventadas.

## Entregas

| Entrega | Artefato |
|---------|----------|
| Teste de 30 segundos | `docs/validation/PRESIDENT_30_SECOND_TEST.md` |
| Telemetria de adoção | `ExecutiveAdoptionService` + rotas `/executive-adoption/*` |
| Revisão dos 4 blocos | `GET /executive-adoption/block-review` |
| Relatório mensal BVG | `GET /monthly-business-value-report?month=YYYY-MM` |
| Homologação webhook | `POST /proactive-notifications/webhook-homologation` |
| Smoke operacional | `scripts/sprint43_executive_validation.py` |

## Quatro blocos revisados

1. **ATTENTION** — O que exige atenção hoje
2. **VALUE** — O que gera mais valor
3. **AI_VALUE** — Valor gerado pela IA (somente validado no total)
4. **PRESIDENCY_ANSWERS** — Perguntas da Presidência

Estados de engajamento: `IGNORED`, `OPENED_ONLY`, `ENGAGED`. Meta de tempo: ≤ 30s por bloco.

## Relatório mensal BVG

O endpoint `/monthly-business-value-report` consolida:

- funil de recomendações (`GENERATED` → `VALIDATED`);
- `businessValueGeneratedByAI` (**VALIDATED_VALUE_ONLY**);
- `estimatedValue` (**ESTIMATED_NOT_REALIZED**);
- EVS, agentes e top recomendações com valor comprovado.

## Webhook externo

Configure `EXECUTIVE_NOTIFICATION_WEBHOOK_URL` no ambiente. Homologue com:

```powershell
curl -X POST "http://127.0.0.1:8046/api/v1/departmental-governance/proactive-notifications/webhook-homologation" `
  -H "Cookie: access_token=<token-owner>" `
  -H "Content-Type: application/json" `
  -d "{}"
```

O ping de homologação **não** contém dados de negócio (`containsBusinessData: false`).

## Regras preservadas

- Insight sem fonte homologada, evidência, linhagem e confiança → bloqueado.
- Ausência de dado ≠ zero.
- Valor estimado nunca entra no total realizado.
- Telemetria de adoção não registra valores financeiros nem perguntas executivas.
- Escopo: empresas 11495, 5555, 74014; departamentos Combustíveis, Conveniência, Lubrificantes.
