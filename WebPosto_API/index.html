✍️ POST — Inserção de Dados

Demonstra como inserir novos registros na API:

📝 Criar Despesas 🔧 Gerenciar Títulos

{fornecedor, descricao, valor, dataVencimento}

✅ Validação em tempo real • HTTP 200 • ID retornado

{fornecedor, descricao, valor, dataVencimento}

✅ Atualização parcial • Validação de ID • Sem perdas de dados
