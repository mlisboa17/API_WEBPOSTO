📊 O QUE É ISTO?
────────────────
Um sistema interativo que demonstra em TEMPO REAL:
  ✅ Leitura de dados (GET)
  ✅ Inserção de dados (POST)
  ✅ Alteração de dados (PUT)

SEM precisar de backend — conecta direto na API WebPosto.


🚀 COMO USAR
────────────

1️⃣  ABRIR O ARQUIVO
   Clique duplo em: dashboard_demo.html
   (Abre automaticamente no navegador)

2️⃣  USAR O DASHBOARD

   LADO ESQUERDO (Ler dados - GET):
   • Clique em "🔄 Carregar Despesas"
   • Mostra lista de TODOS os títulos a pagar
   • Atualiza totais e estatísticas

   LADO DIREITO (Criar/Alterar - POST/PUT):

   📌 ABA "Criar Nova":
      - Preencha: Fornecedor, Valor, Vencimento, Descrição
      - Clique em "💾 Criar Despesa"
      - Novo título é salvo na API WebPosto
      - Aparece na tabela automáticamente

   📌 ABA "Alterar Existente":
      - Selecione um título da lista
      - Modifique os dados
      - Clique em "✏️ Alterar Despesa"
      - Mudanças são salvas na API WebPosto

3️⃣  VER O LOG
   Abaixo mostra TODAS as operações HTTP
   Prova que funciona:
   • Timestamp de cada operação
   • Tipo (GET, POST, PUT)
   • Dados enviados/recebidos

📞 DÚVIDAS?
───────────
Se o dashboard não carregar dados:

1. Verifique conexão de internet
2. Abra o console do navegador (F12 → Console)
3. Procure por erros CORS
4. Se houver erro de chave, contate suporte Quality Automação

Se houver erro "CORS blocked":
• É normal em alguns navegadores
• Em produção, usar backend proxy
• Para testes locais, pode usar extensão "CORS Unblock"
