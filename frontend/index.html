Como Usar

1. Selecione um Endpoint

Na barra lateral, clique em um endpoint para selecioná-lo.

2. Configure a Requisição

  • Adicione query parameters se necessário
  • Para POST/PUT, preencha o body JSON
  • Adicione token se necessário

3. Envie a Requisição

Clique em "Enviar Requisição" e veja o resultado em tempo real.

🔧 Módulos Disponíveis

📊 Códigos HTTP

  • 200: Sucesso
  • 201: Criado
  • 400: Erro de validação
  • 401: Não autorizado
  • 404: Não encontrado
  • 500: Erro interno
